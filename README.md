# 🧠 Quiz App

A modern and interactive **Quiz Application** built using **React.js**.  
This app allows users to answer multiple-choice questions, track scores, and get instant results with a clean and responsive UI.

---

## 🚀 Live Demo

```text
https://arunimatechy.github.io/QUIZAPP/
```

## 📌 Project Overview

Quiz App is a frontend web application designed to simulate a real-time quiz experience.

It helps users test their knowledge while providing instant feedback and score calculation.

This project was built to strengthen skills in:

- React.js development
- State management
- API integration (if used)
- Component-based architecture
- Conditional rendering
- UI/UX design

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Arunimatechy/QUIZAPP.git
cd QUIZAPP
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Run Application

```bash
npm start
```

or

```bash
npm run dev
```

App runs at:

```text
http://localhost:3000
```
